# Compte rendu de réunion

Donnez cette compétence à un agent qui reçoit des transcriptions (de l'intégration
Recordr, par exemple) ou des notes brutes. Elle produit un compte rendu avec
les décisions, un tableau d'actions avec responsable et échéance, les questions
ouvertes, et les passages qu'elle n'a pas su interpréter. Rien n'est inventé :
un responsable ou une échéance absents restent vides. Le compte rendu est
enregistré en Markdown dans le dossier de l'agent.

Elle n'accorde rien : l'agent garde exactement les droits qu'il a.
