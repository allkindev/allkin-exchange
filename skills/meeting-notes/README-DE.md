# Besprechungsprotokoll

Gib diese Fähigkeit einem Agenten, der Transkripte (etwa von der Integration Recordr)
oder grobe Notizen erhält. Sie erstellt ein Protokoll mit den Entscheidungen,
einer Aufgabentabelle mit Verantwortlichen und Fristen, den offenen Fragen und
den Stellen, die sie nicht deuten konnte. Nichts wird erfunden: Fehlt ein
Verantwortlicher oder eine Frist, bleibt das Feld leer. Das Protokoll wird als
Markdown im Ordner des Agenten gespeichert.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
