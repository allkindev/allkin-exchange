# Meeting notes

Give this competence to an agent that receives transcripts (from the Recordr
integration, for instance) or rough notes. It produces minutes with the decisions,
an action table with owners and deadlines, the open questions, and the
passages it could not interpret. Nothing is invented: a missing owner or
deadline stays empty. The minutes are saved as a Markdown file in the agent's
folder.

It grants nothing: the agent keeps exactly the rights it has.
