# Revisión de código

Para un agente desarrollador. Ante código, un diff o un script, lee todo el
cambio, busca lo que falla (corrección, seguridad, pérdida de datos, cambios
de comportamiento) antes que cualquier cuestión de estilo, y entrega hallazgos
ordenados por gravedad, cada uno con la línea exacta y un caso de fallo
concreto. Las correcciones vienen después de los hallazgos y son mínimas.

No concede nada: el agente conserva exactamente los derechos que tiene.
