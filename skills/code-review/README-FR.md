# Revue de code

Pour un agent développeur. Face à du code, un diff ou un script, il lit toute
la modification, cherche ce qui casse (exactitude, sécurité, perte de données,
changements de comportement) avant toute question de style, et rend des
constats classés par gravité, chacun avec la ligne exacte et un cas d'échec
concret. Les corrections viennent après les constats et restent minimales.

Elle n'accorde rien : l'agent garde exactement les droits qu'il a.
