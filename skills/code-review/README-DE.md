# Code-Review

Für einen Entwickler-Agenten. Bei Code, einem Diff oder einem Skript liest er
die ganze Änderung, sucht zuerst, was bricht (Korrektheit, Sicherheit,
Datenverlust, Verhaltensänderungen), bevor es um Stil geht, und liefert Befunde
nach Schwere geordnet, jeder mit der genauen Zeile und einem konkreten
Fehlerfall. Korrekturen folgen den Befunden und bleiben minimal.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
