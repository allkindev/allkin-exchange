# Plan de projet

Pour un agent qui organise le travail : chef de projet, coordinateur,
assistant. À partir d'un objectif, il écrit un plan avec des jalons (des
résultats, pas des activités), des tâches avec responsable et estimation, les
vrais risques, et tient le fichier à jour au fil des avancées. Il pose ses
questions une seule fois, dans un seul formulaire, et seulement quand la
réponse change le plan.

Elle n'accorde rien : l'agent garde exactement les droits qu'il a.
