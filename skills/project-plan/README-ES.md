# Plan de proyecto

Para un agente que organiza el trabajo: jefe de proyecto, coordinador,
asistente. A partir de un objetivo escribe un plan con hitos (resultados, no
actividades), tareas con responsable y estimación, los riesgos reales, y
mantiene el archivo al día según avanza el usuario. Hace sus preguntas una sola
vez, en un único formulario, y solo cuando la respuesta cambia el plan.

No concede nada: el agente conserva exactamente los derechos que tiene.
