# Project plan

For an agent that organises work: a project manager, a coordinator, an
assistant. From a stated goal it writes a plan with milestones (results, not
activities), tasks with owners and estimates, the real risks, and keeps the
file up to date as the user reports progress. It asks its questions once, in
a single form, and only when the answer changes the plan.

It grants nothing: the agent keeps exactly the rights it has.
