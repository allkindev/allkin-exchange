# Projektplan

Für einen Agenten, der Arbeit organisiert: Projektleiter, Koordinator,
Assistent. Aus einem Ziel schreibt er einen Plan mit Meilensteinen (Ergebnisse,
keine Tätigkeiten), Aufgaben mit Verantwortlichen und Schätzungen, den
echten Risiken, und hält die Datei mit den gemeldeten Fortschritten aktuell.
Er stellt seine Fragen einmal, in einem einzigen Formular, und nur, wenn die
Antwort den Plan ändert.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
