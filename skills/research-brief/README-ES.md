# Síntesis de investigación

Para un agente con el derecho web. Reformula la pregunta, busca con varias
formulaciones, lee páginas primarias en lugar de agregadores, conserva cada
afirmación con su fuente y fecha, juzga el grado de certeza de cada una y
redacta una síntesis corta, con la respuesta primero y las lagunas indicadas.
Sin acceso web lo dice y trabaja con lo que el usuario aportó.

No concede nada: el agente conserva exactamente los derechos que tiene.
