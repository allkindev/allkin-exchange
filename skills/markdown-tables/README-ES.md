# Tablas Markdown

Una competencia para todo agente que redacta comparaciones: le enseña cuándo
una tabla es la forma adecuada, cómo mantenerla legible en la conversación de
Allkin (cuatro columnas, celdas cortas, números alineados), y cómo introducirla
y concluirla.

Dásela a un agente desde su página (sección Alcance → Competencias) o desde
esta página (Agentes que la tienen). El agente solo lee su nombre y su
descripción hasta que surge una comparación; entonces carga el procedimiento.

No concede nada: el agente conserva exactamente los derechos que tiene.
