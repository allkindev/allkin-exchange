# Markdown tables

A competence for every agent that writes comparisons: it teaches when a table is
the right shape, how to keep it readable in Allkin's conversation (four columns,
short cells, aligned numbers), and how to introduce and conclude it.

Give it to an agent from its page (section Reach → Competences) or from this
page (Agents that have it). The agent reads only its name and description until
a comparison comes up; it then loads the procedure.

It grants nothing: the agent keeps exactly the rights it has.
