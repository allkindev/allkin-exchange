# Markdown-Tabellen

Eine Fähigkeit für jeden Agenten, der Vergleiche schreibt: Sie lehrt ihn, wann
eine Tabelle die richtige Form ist, wie sie in Allkins Unterhaltung lesbar
bleibt (vier Spalten, kurze Zellen, ausgerichtete Zahlen) und wie man sie
einleitet und abschließt.

Gib sie einem Agenten auf seiner Seite (Abschnitt Reichweite → Fähigkeiten) oder
auf dieser Seite (Agenten, die sie haben). Der Agent liest nur Namen und
Beschreibung, bis ein Vergleich ansteht; dann lädt er die Anleitung.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
