# Tableaux Markdown

Une compétence pour tout agent qui rédige des comparaisons : elle lui apprend
quand un tableau est la bonne forme, comment le garder lisible dans la
conversation d'Allkin (quatre colonnes, cellules courtes, nombres alignés), et
comment l'introduire et le conclure.

Donnez-la à un agent depuis sa page (section Portée → Compétences) ou depuis
cette page (Agents qui l'ont). L'agent n'en lit que le nom et la description
jusqu'à ce qu'une comparaison se présente ; il charge alors la procédure.

Elle n'accorde rien : l'agent garde exactement les droits qu'il a.
