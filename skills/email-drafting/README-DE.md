# E-Mails verfassen

Für jeden Agenten, der E-Mails und Nachrichten schreiben oder beantworten
soll. Er klärt Empfänger, Ziel und Register, beginnt mit dem Wesentlichen,
hält eine Bitte pro E-Mail mit Frist ein und liefert Betreff und Text fertig
zum Einfügen. Eine Antwort behandelt jeden Punkt der erhaltenen Nachricht der
Reihe nach.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
