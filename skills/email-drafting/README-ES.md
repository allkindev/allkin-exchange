# Redacción de correos

Para cualquier agente al que se pida escribir o responder correos y mensajes.
Fija el destinatario, el objetivo y el registro, empieza por lo esencial,
mantiene una sola petición por correo con una fecha, y entrega un asunto y un
cuerpo listos para pegar. Una respuesta trata cada punto del mensaje recibido
en orden.

No concede nada: el agente conserva exactamente los derechos que tiene.
