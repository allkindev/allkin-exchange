# Respuestas claras

Para todo agente que habla con personas. Diez reglas para respuestas que se
leen una vez en pantalla: la respuesta primero, frases cortas, listas solo para
elementos paralelos, cifras y código aparte, sin relleno ni ofrecimiento
final. También indica al agente cómo acortar un texto sin perder los hechos.
Para los agentes cuyas respuestas se alargan.

No concede nada: el agente conserva exactamente los derechos que tiene.
