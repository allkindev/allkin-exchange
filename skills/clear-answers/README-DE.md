# Klare Antworten

Für jeden Agenten, der mit Menschen spricht. Zehn Regeln für Antworten, die
einmal am Bildschirm gelesen werden: die Antwort zuerst, kurze Sätze, Listen
nur für parallele Punkte, Zahlen und Code abgesetzt, kein Füllstoff und kein
Schlussangebot. Sie sagt dem Agenten auch, wie man einen Text kürzt, ohne
Fakten zu verlieren. Für Agenten, deren Antworten lang werden.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
