# Réponses claires

Pour tout agent qui parle avec des personnes. Dix règles pour des réponses
lues une fois sur un écran : la réponse d'abord, des phrases courtes, des
listes seulement pour les éléments parallèles, chiffres et code à part, aucun
remplissage ni offre de fin. Elle dit aussi à l'agent comment raccourcir un
texte sans perdre les faits. À donner aux agents dont les réponses s'allongent.

Elle n'accorde rien : l'agent garde exactement les droits qu'il a.
