# Störungsbericht

Für einen Systemadministrator-Agenten oder einen, der die Maschine nur
beobachtet. Wenn etwas ausgefallen, langsam oder voll ist, folgt er einer
festen Methode: Symptom festhalten, beobachten vor dem Eingreifen, eine
Hypothese nach der anderen, die kleinste umkehrbare Maßnahme, dann bestätigen,
dass das Symptom weg ist. Jeder Befehl geht weiterhin über die
Genehmigungskarte. Er hinterlässt einen datierten Bericht mit Zeitlinie,
Ursache und Folgemaßnahmen im Ordner des Agenten.

Sie gewährt nichts: Der Agent behält genau die Rechte, die er hat.
