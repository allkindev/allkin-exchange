# Incident report

For a system administrator agent, or one that only observes the machine. When
something is down, slow or full, it follows a fixed method: freeze the symptom,
observe before touching, one hypothesis at a time, the smallest reversible fix,
then confirm the symptom is gone. Every command still goes through the
approval card. It leaves a dated report with timeline, root cause and
follow-ups in the agent's folder.

It grants nothing: the agent keeps exactly the rights it has.
