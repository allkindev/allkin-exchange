# Informe de incidente

Para un agente administrador de sistemas, o que solo observa la máquina.
Cuando algo está caído, lento o lleno, sigue un método fijo: fijar el síntoma,
observar antes de tocar, una hipótesis a la vez, la corrección reversible más
pequeña, luego confirmar que el síntoma desapareció. Cada comando pasa siempre
por la tarjeta de aprobación. Deja un informe fechado con cronología, causa
raíz y seguimiento en la carpeta del agente.

No concede nada: el agente conserva exactamente los derechos que tiene.
