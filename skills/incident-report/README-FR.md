# Rapport d'incident

Pour un agent administrateur système, ou qui observe seulement la machine.
Quand quelque chose est en panne, lent ou plein, il suit une méthode fixe :
figer le symptôme, observer avant de toucher, une hypothèse à la fois, la
correction réversible la plus petite, puis confirmer que le symptôme a disparu.
Chaque commande passe toujours par la carte d'approbation. Il laisse un
rapport daté avec chronologie, cause et suites dans le dossier de l'agent.

Elle n'accorde rien : l'agent garde exactement les droits qu'il a.
