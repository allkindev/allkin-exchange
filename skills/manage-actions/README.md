# Manage actions

For an agent that has the right "Can schedule actions": with this competence it may create, read
and delete Allkin's actions — at a time (every morning, each Monday…) or on an event of the event
log (a refused sign-in, an agent that fails, an update). Each creation and each deletion waits for
your approval, and an action's run has exactly the rights of the agent it wakes.

It is a second key, never a wider right: without the right "Can schedule actions" it does
nothing, and without it an agent that has the right can only read the actions. Only you give it
to an agent.
