# Gestionar acciones

Para un agente que tiene el derecho «Puede programar acciones»: con esta competencia puede crear,
consultar y eliminar las acciones de Allkin — a una hora fija (cada mañana, cada lunes…) o ante un
evento del registro (un inicio de sesión rechazado, un agente que falla, una actualización). Cada
creación y cada eliminación espera tu aprobación, y la ejecución de una acción tiene exactamente
los derechos del agente al que despierta.

Es una segunda llave, nunca un derecho más: sin el derecho «Puede programar acciones» no hace nada;
sin ella, un agente que tiene ese derecho solo puede consultar las acciones. Solo tú se la das a un
agente.
