# Gérer les actions

Pour un agent qui a le droit « Peut planifier des actions » : avec cette compétence, il peut créer,
relire et supprimer les actions d'Allkin — à heure fixe (chaque matin, chaque lundi…) ou sur un
événement du journal (une connexion refusée, un agent en échec, une mise à jour). Chaque création
et chaque suppression attend votre approbation, et l'exécution d'une action a exactement les droits
de l'agent qu'elle réveille.

C'est une seconde clé, jamais un droit de plus : sans le droit « Peut planifier des actions », elle
ne fait rien ; sans elle, un agent qui a ce droit peut seulement lire les actions. Vous seul la
donnez à un agent.
