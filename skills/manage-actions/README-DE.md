# Aktionen verwalten

Für einen Agenten mit dem Recht „Darf Aktionen planen“: Mit dieser Fähigkeit kann er die Aktionen
von Allkin anlegen, lesen und löschen – zu einer festen Zeit (jeden Morgen, jeden Montag …) oder bei
einem Ereignis des Protokolls (eine abgelehnte Anmeldung, ein Agent mit Fehler, ein Update). Jede
Erstellung und jedes Löschen wartet auf deine Freigabe, und die Ausführung einer Aktion hat genau
die Rechte des Agenten, den sie weckt.

Sie ist ein zweiter Schlüssel, nie ein zusätzliches Recht: Ohne das Recht „Darf Aktionen planen“
bewirkt sie nichts; ohne sie kann ein Agent mit diesem Recht die Aktionen nur lesen. Nur du gibst
sie einem Agenten.
